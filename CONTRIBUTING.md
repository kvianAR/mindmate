# Contributing

Start with an issue describing the problem, expected result and a small reproducible example. For code changes, create a branch and submit a focused pull request with the reason for the change and the checks you ran.

- Keep private credentials, real user data and sensitive screenshots out of issues and commits.
- Copy `.env.example` for local setup when provided; never commit a populated environment file.
- Preserve attribution and keep README instructions aligned with implemented behavior.
- Do not present illustrations, sample data or planned features as live product evidence.

For Node.js apps, use the documented Node version, then run `npm ci`, `npm test`, `npm run lint` and `npm run build`. AI and database features may need separate environment configuration.

For the HTML/CSS portfolio, check desktop and mobile widths, keyboard navigation and project links. For Glok, follow the macOS setup and local test instructions in the README.
